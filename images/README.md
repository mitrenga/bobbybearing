# images/

`poster.png` is the game's poster (1448 × 1086, supplied by the operator
2026-10-31), `cover.png` is its 800 × 600 reduction (palette PNG8) for
`/about` (`../aboutPage.php`), the same shape as the siblings':

    convert poster.png -resize 800x600 -colors 256 -strip PNG8:cover.png

`app-icon.svg` (supplied by the operator 2026-10-31) is a smiling silver
ball with turquoise neon outlines, after the poster. It is a drawing, not
graphics taken out of the original. The canvas is 1024 × 1024 and all the
artwork, glow included, stays inside the middle 800 × 800 square, so that a
launcher's mask (`purpose: maskable`) does not cut it.

The PNG set and the favicon are made from it by the library's tools (by hand,
like a build), run in this directory:

- `../app/svision/tools/make-app-icons` — `app-icon.svg` → PNG set
  (192, 256, 512, 1024, 1980), needs `rsvg-convert`
- `../app/svision/tools/make-favicon` — `favicon.ico`, copied to the
  project root (`../favicon.ico`) as well

The web app manifest is not a file: `manifest.webmanifest` is generated by
`app/svision/php/manifestPage.php` from `index.php` (`$appName`) and lists
the PNG set and `app-icon.svg`. `poster.png` is the Open Graph image of
`index.php`, `cover.png` the picture of `aboutPage.php`.

★ **Never copy another game's icons here**: a sibling's favicon taken over
would be a picture of a foreign game, which is worse than none.
